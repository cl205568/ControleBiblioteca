Controle de Biblioteca



Aluno: Tiago



O Controle de Biblioteca é um sistema desenvolvido para facilitar o gerenciamento de livros, usuários e empréstimos de uma biblioteca.



Objetivo:

Organizar o cadastro de livros e usuários e facilitar o controle dos empréstimos e devoluções.



Público-alvo:

O sistema é destinado a bibliotecas e seus funcionários, auxiliando no gerenciamento dos livros e dos empréstimos realizados pelos usuários.



Principais funcionalidades:

\- Cadastro de livros

\- Consulta de livros

\- Cadastro de usuários

\- Controle de empréstimos

\- Renovação de empréstimos
